# Hello Web

หน้าเว็บเปล่า มีข้อความ **Hello** ตรงกลางจอ

## ไฟล์ที่เปิดดูได้

| สิ่งที่เห็น | ไฟล์ |
|---|---|
| หน้าเว็บ | `web/wwwroot/index.html` |
| สี/จัดวาง | `web/wwwroot/css/styles.css` |
| JavaScript | `web/wwwroot/js/main.js` |

## รันใน Visual Studio

1. เปิดไฟล์ `camera.slnx` (หรือเปิด `web/HelloWeb.csproj` โดยตรง)
2. ใน Solution Explorer คลิกขวาโปรเจกต์ **HelloWeb** → **Set as Startup Project**
3. กด **F5** (หรือปุ่ม Run)

เบราว์เซอร์จะเปิดหน้า `http://localhost:5080` ให้เอง

## เปิดดูไฟล์อย่างเดียว

ดับเบิลคลิก `web/wwwroot/index.html` เพื่อเปิดในเบราว์เซอร์โดยไม่ต้องรันโปรเจกต์
